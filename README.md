## 快速体验（3 条命令）

```bash
cd "03_项目主体_Pulse"
python3 pulse.py demo        # 写入 8 周真实数据
python3 pulse.py analyze     # 看动力曲线 + 缓亡预警
python3 pulse.py dashboard   # 生成 output/dashboard.html，浏览器打开
python3 -m unittest discover -s tests -q   # 13 项测试全绿
```

核心证据：
```bash
python3 pulse.py analyze --data "../07_验收/W5时刻数据快照.json"
# → 缓亡风险：85/100 [critical] 危险  ← 工具在最低谷准确报警
```

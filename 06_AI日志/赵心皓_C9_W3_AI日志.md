## Week 3 AI 使用记录（2026-10-15）

**本周任务**：让 AI 生成 SVG 折线图与 HTML 仪表盘骨架。

**迭代 1** — SVG 生成
- Prompt："用纯 Python 生成一段内嵌 SVG 折线图：viewBox 720x300，y 轴 1-10 网格，画数据点、数值标签、面积填充。浅色主题，无外部依赖。"
- AI 输出：坐标计算框架正确，但用 f-string 拼了整页 HTML，CSS 的大括号被当成 Python 表达式，渲染崩溃。
- 我定位：浪费一小时后确认是 f-string 与 `{}` 冲突。

**迭代 2** — 模板方案替换
- Prompt："CSS 大括号和 f-string 冲突。请改用 str.format()，CSS 里的 { } 写成 {{ }}，把样式与脚本分离。"
- AI 输出：可运行的模板方案。
- 采纳：✅ 采纳，并加 `html.escape()` 防止数据里的特殊字符破坏页面。

**迭代 3** — 分享口径优化
- Prompt："帮我把本周成果写成一句能发在 Elite20 群的话，突出'零依赖、双击即开'。"
- AI 输出 3 个版本，我选了最朴实的一版（避免营销腔）。

**心得**：生成代码时，模板转义规则要先于内容考虑；加上"无外部依赖、可离线打开"的硬约束，才符合拿来主义调研得出的本地优先原则。

# 赵心皓_C9_AAR_W1.md

## C9 Weekly AAR — Week 1（2026-10-01）

### 做了什么
- **本周产出**：`赵心皓_C9_mvp.py`（MVP v0.1）+ `sample_week.json` + 真实运行输出 `mvp_sample_output.txt`。脚本读取单周 AAR 的 JSON，提取动力分数，输出带文本条的结构化报告。
- **公开在哪里**：Elite20 群（附命令行输出截图）；代码本地留存，W6 起开源到 GitHub。
- **关键动作**：把"想法"变成"能跑的东西"——这是本周唯一但最重要的目标，达成了。

### 哪些有效
- **极简范围**有效：只做"单周 JSON → 文本报告"一件事，不碰可视化、不碰多周数据，让我在第一个周末就跑通了完整链路，而不是陷入设计泥潭。
- **AI 辅助 + 手工调试**的组合有效：让 AI 生成初稿框架，我逐行读、逐行跑，保持了掌控感（详见本周 AI 日志）。
- **真实数据驱动**有效：用自己 Week 1 的真实记录做样例，而不是编造数据，报告一出来我就知道它有没有用。

### 哪些无效
- **AI 生成的初稿藏了一个 bug**：我直接采用了 `week = data.get("week", data)` 这行解包逻辑。样例 JSON 里 `"week": 1` 是周次数字，于是 `week` 变成了整数 1，传入 `render()` 后 `key not in week` 触发 `TypeError: argument of type 'int' is not iterable`。
  - **为什么失败**：我假设了"week 字段是对象"，但真实数据里它是数字——典型的"没跑过真实数据就相信代码"的失误。
  - **如何修**：改为显式类型判断（含 `motivation` 字段即为周对象 / `week` 为 dict 时取内层 / 否则降级），并加注释记录。教训：**MVP 的第一价值不是完美，而是用真实数据把隐藏假设炸出来**。
- **输出只有终端文本**：不好看、不便分享，这是我刻意留到 V2 的缺口，但分享时确实打了折扣。

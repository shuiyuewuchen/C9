## C9 Weekly AAR — Week 3（2026-10-15）

### 做了什么
- **本周产出**：V2 初版 —— 内嵌 SVG 的动力折线图、HTML 仪表盘骨架（含标题、图表区、明细表占位）、内置 demo 数据入口。
- **公开在哪里**：Elite20 群（发了一段仪表盘截图，收到 2 条"这个有意思"的反馈）。
- **关键动作**：把"终端里的文字"变成"浏览器里的图"，成果第一次具备可展示性。

### 哪些有效
- **单文件内嵌 SVG** 的决策非常有效：不引外部 JS 库、不联网，HTML 双击即开，分享成本几乎为零。这直接来自拿来主义调研里 Obsidian 的"本地优先"原则。
- **让 AI 生成 SVG 坐标计算框架、我手工校准**有效：AI 很快给出折线 + 网格的结构，我只需调整 viewBox 与坐标映射。
- **公开收到正反馈**有效：两条"有意思"的回复，是外部动力的低成本补充。

### 哪些无效
- **f-string 与 CSS 大括号冲突**：初版用 f-string 拼整页 HTML，CSS 里的 `{ }` 被当成 Python 表达式，模板渲染直接崩，调试花了一小时。
  - **为什么失败**：把"代码字符串"和"样式文本"混在一个 f-string 里，没做转义规划。
  - **如何修**：改用 `.format()` 并把 CSS 大括号写成 `{{ }}`，同时把样式抽到独立段落。教训：**生成代码时，模板引擎的转义规则要先于内容本身考虑**。
- **时间被 C8 挤压**：C8 真实项目进入交付高峰，本周实际投入只有计划的 60%，仪表盘只完成骨架、风险模块没动。虽然达标线是"骨架跑通"，但进度明显放缓。
